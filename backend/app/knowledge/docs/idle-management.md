## Overview

Not all idle time is the same, and treating it as a single number hides
what is actually happening on site. Idle time on a loaded machine
generally falls into a few distinct categories: planned breaks, machine
faults, weather stoppages, waiting on site logistics (most commonly a haul
truck that hasn't arrived), and time an individual operator spends idle
beyond what the task and conditions would normally require.

## Why Attribution Matters

Lumping all idle time together and attributing it to the operator is both
inaccurate and unfair. If a machine sits idle because no haul truck is
available, that is a site logistics problem, not an operator performance
problem. Correctly separating these causes protects operators from being
blamed for delays outside their control, and gives supervisors an accurate
picture of where site throughput is actually being lost.

## What Counts As Operator-Attributable Idle

Idle time is reasonably attributed to the operator when none of the other
explanations apply: the machine is not in a scheduled break, there is no
active machine fault, weather conditions are not forcing a stop, and a
truck or work is actually available. Even then, a single idle window above
expectation is not unusual — a sustained pattern across multiple
consecutive windows, well above what similar operators show in the same
conditions, is the signal worth a conversation.

## Reading A Deviation Flag

A deviation flag compares an operator's idle ratio in a given context
(task type, weather, their own skill level) against the expected ratio for
that same context, using their own or similar operators' history — not
against a single fixed number. A flag means the ratio was meaningfully
higher than expected for two or more consecutive windows, not a one-off
event.

## Recommended Response

When idle deviation is flagged, check the attribution breakdown first. If
site or weather causes dominate, address the logistics issue. If
operator-attributed idle genuinely dominates and persists, have a direct,
non-punitive conversation focused on what's slowing the operator down.
